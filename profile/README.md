<p>几十个号分开养，采购单上通常只有一行「代理费」，看着便宜就签了。半年后再算账，会发现真正贵的是折损：号掉一个，重新养的时间成本远超省下的那点差价。住宅和机房两种出处的差别，本质不在单价，而在单位可用号的落地成本。这篇把四笔账拆开，按每个号每月摊，最后给一个判断表，看清什么情况下机房段其实够用。</p>
<h2>一、两种出处的单价差在哪</h2>
<p>机房地址段来自数据中心，一个 C 段能切出几百个 IP，边际成本极低，报价常见每条每月两三元到八元；原生家宽受限于当地宽带线路，一条线只能出少量地址，报价常见每条每月三十元到八十元，动态按流量计费的方案多在每 GB 一到三元区间。差距五到十倍是常态，价格区间仅供参考。</p>
<h3>为什么家宽贵这么多</h3>
<p>供给端决定的。家宽线路要么靠当地合作方装宽带，要么靠聚合多户家庭网络，无论哪种，落地、维护、换线都要人力。机房只要开虚拟机就能批量出地址，成本结构完全不同。所以便宜的那一方永远便宜，别指望用价格谈判把差距抹平。</p>
<h3>贵的地方是不是你想要的地方</h3>
<p>关键问题是：你买的到底是「IP 数量」还是「看起来像真实用户的出口」。只做公开数据采集、不涉及登录态的任务，地址类型几乎不影响结果；需要长期保持登录、需要稳定的地区归属、需要和其他信息对得上的场景，地址类型就是主要变量。先想清楚这一点，再谈贵不贵。</p>

<h3>折损怎么折算成钱</h3>
<p>一个号的重建成本等于：注册耗时、首周养护耗时、期间消耗的线路费，加上业务中断带来的机会损失。假设重建要两小时人工、每小时人力成本四十元，单次折损就是八十元起。机房方案每月折损一成，三十个号就是三个号，仅人工一项每月两百四十元，还没算中断损失。</p>
<h3>容易被漏算的两笔</h3>
<p>第一笔是试错成本，便宜方案往往要多试几轮才找到能用的段，试错期间的订阅费和人力都是沉没的。第二笔是切换成本，服务商换了供应商，你要跟着重配环境和台账，这部分在合同里通常不会写。</p>

<h2>三、看出处的三个硬指标</h2>
<p>不管卖家怎么说，出处只能靠查。三个指标按顺序看：ASN 归属机构、whois 登记信息、反向解析命名。三项都指向当地运营商，才算原生家宽；只要有一项落在托管商名下，就按机房段对待。</p>
<h3>ASN 是最快的筛子</h3>
<p>在 bgp.he.net 输入 IP，看 origin AS 的机构名。Comcast、Verizon、AT&T、Deutsche Telekom、Orange、Vodafone 这类是运营商；DigitalOcean、Vultr、Hetzner、OVH、阿里云国际这类是托管商。同一批 IP 里混着两种 ASN，说明这批是拼凑的，稳定性要打问号。</p>
<h3>同段密度也要看</h3>
<p>把几个 IP 的斜杠二十四段拿去反查，看这一段里有多少地址被公开标注为代理。密度过高意味着这段被大量出售，邻居的行为会影响你的出口声誉。这个指标没有官方口径，但用公开的 IP 信誉查询能看个大概。</p>
<h2>四、什么情况下机房段其实够用</h2>
<p>不是所有业务都要买贵的。判断标准看三个条件：有没有登录态、要不要长期保持同一出口、账号是否与其他真实信息绑定。三个条件都不满足，机房段完全够用，省下的钱可以投在环境质量上。</p>

<h2>常见问答</h2>
<h3>机房 IP 是不是一定不能用？</h3>
<p>答：不是。地址类型只是变量之一，关键看业务是否需要稳定的身份连续性。纯读取类任务用机房段很常见，成本低、速度快。需要长期登录的场景才需要更接近真实用户的出口。</p>
<h3>便宜的住宅 IP 能不能买？</h3>
<p>答：先查再判断。价格明显低于市场区间时，多半是机房段冒充，或者是一条线切给多个用户。用 ASN 和同段密度两个指标一查就能看个大概，查完再决定要不要小量试用。</p>
<h3>折损率怎么统计才准？</h3>
<p>答：按周记，记两个数：本周新增异常号数、本周彻底不可用号数。用后者除以上周总号数就是折损率。连续记四周再看趋势，单周数据波动大，容易误判。</p>
<h3>混合方案怎么分配比例？</h3>
<p>答：按业务重要度分。核心号占两成到三成，全部走家宽并独立成池；辅助号走机房段，允许轮换。比例不是固定的，每季度按折损数据调一次，把折损高的那部分往上提一档。</p>
